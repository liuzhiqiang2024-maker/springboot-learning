# 基于 SpringBoot 的高性能个人博客系统

## 📖 项目简介
本项目是一个前后端分离的单体架构博客系统，包含用户认证、文章管理、多级评论、点赞互动等核心业务。在开发过程中，不仅实现了基础 CRUD，还针对高并发读写、系统解耦、接口性能进行了深度优化。

## 🛠️ 技术栈
- **核心框架**：Java 17, SpringBoot 4.x, MyBatis
- **数据存储**：MySQL, Redis
- **消息中间件**：RabbitMQ
- **安全鉴权**：JWT, Spring Security Crypto
- **工具链**：Maven, Git, Docker (计划中)

## 🚀 核心功能与技术亮点

### 1. 登录鉴权与安全 (JWT)
- 基于 **JWT 与自定义拦截器** 实现无状态登录鉴权，避免集群环境下的 Session 共享问题。
- 采用 **BCrypt** 对用户密码进行加盐哈希加密，防止彩虹表攻击。
- 设计 Token 黑名单机制（规划中），保障用户安全登出。

### 2. 高并发点赞系统 (Redis)
- 针对文章点赞高并发场景，摒弃直接操作数据库的同步做法。
- 采用 **Redis 的 Set 数据结构** 存储点赞用户 ID，利用其天然去重特性实现防重复点赞。
- 设计定时任务/异步机制将点赞数据落库到 MySQL，有效提升接口吞吐量，保护数据库免受洪峰冲击。

### 3. 异步通知与系统解耦 (RabbitMQ)
- 引入 **RabbitMQ** 解决文章发布后的业务耦合与响应延迟问题。
- 使用 **Direct 交换机** 将邮件通知精准路由，使用 **Fanout 交换机** 广播站内信和积分发放。
- 实现主业务与边缘业务的异步解耦，极大提升了发布接口的响应速度。

### 4. 数据查询与性能优化 (MySQL + Redis)
- 针对文章详情页的多表（文章、作者、分类、标签）关联查询，采用 `LEFT JOIN` + MyBatis `resultMap` 手动映射优化。
- 引入 **Redis** 构建热点文章详情缓存，设置合理 TTL 防止缓存雪崩与穿透。
- 文件上传模块采用 `UUID` 重命名防止覆盖，并配置静态资源映射。
